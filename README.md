# 오늘도 하나씩

반복되는 집안일을 나눠서 놓치지 않게 하는 앱. 범용 할 일 관리 앱이 아니다.

**https://everyeight.vercel.app**

8일마다 화장실 청소를 기억해서 앱을 여는 사람은 없다. 그래서 이 앱은
"완료할 때 다음 한 건만 만드는" 규칙 하나를 중심으로 짜여 있다.

---

## 돌리기

```bash
npm install
cp .env.example .env.local   # Supabase 열쇠를 채운다 (없어도 돌아간다)
npm run dev                  # http://localhost:3000
npm test                     # 반복 주기 규칙 테스트
npm run build
npm run icons                # 강조색이 바뀌었을 때 앱 아이콘 다시 뽑기
```

`.env.local`이 비어 있으면 로그인 없이 이 기기 안에서만 도는 상태로 돌아간다.
반쯤 붙은 채로 로그인 벽만 세우면 앱을 아예 못 쓰게 되기 때문이다.

## 구조

```
화면(screens, sheets, components)
      ↓  useStore() / useUi() / useAuth()
상태(lib/store.tsx, lib/ui.tsx, lib/auth.tsx)
      ↓  Repository 인터페이스
저장(lib/repo/*)  ──  로컬(IndexedDB)  +  서버(Supabase)
```

화면은 저장소를 직접 부르지 않는다. 스토어는 Supabase를 모른다.
그래서 2단계를 붙일 때 화면을 거의 손대지 않았다.

## 지켜둔 것

- **미래 회차를 미리 만들지 않는다.** 완료할 때 다음 1건만.
  기준일은 실제로 체크한 날과 그 할 일의 날짜 중 **늦은 쪽**이다
- **모든 쓰기는 낙관적.** 체크하면 화면이 먼저 바뀌고 저장은 뒤에서 조용히 간다
- **화면은 늘 로컬을 본다.** 서버 응답을 기다리지 않아서 지하철에서도 열린다
- **합칠 때 목록을 통째로 덮지 않는다.** 항목 단위로 늦게 고친 쪽이 이긴다
- **지우기는 흔적을 남긴다.** 서버는 `deleted_at`, 로컬은 무덤.
  진짜로 지우면 다음 동기화에 되살아난다
- 밀린 일을 빨갛게 칠하지 않는다. `3일 지남`이라고만 적는다
- 완료한 항목을 숨기지 않는다. 아래로 내리고 취소선만 긋는다
- 메모는 일별 화면에서만 보인다 (`screens/day/TaskRow.tsx`만 메모를 그린다)
- 카테고리를 지우면 그 안의 할 일은 남은 카테고리로 옮겨진다
- 필터를 켜도 앱 강조색은 안 바뀐다. 누른 칩만 자기 색을 입는다
- 장보기는 할 일이 아니다. 날짜도 주기도 없다

## 아직 안 한 것

- **방과 초대 링크.** DB(`create_room`, `join_room`)는 있고 화면이 없다. 지금은 각자 자기 목록만 본다
- **실시간.** 앱 열 때 한 번만 맞춘다
- **알림(3단계).** 아침에 오늘 할 일 한 줄. 서버 cron이 필요하다
- 삭제 되돌리기, 내보내기, 홈 화면 위젯
