# 방 배경 규격

**곰돌이가 서는 자리를 비워두는 것**이 이 문서의 전부다.
숫자는 앱에서 재어 낸 것이라, 앱이 바뀌면 [다시 재야 한다](#숫자가-어디서-나왔나).

---

## 한 장 요약

| | |
|---|---|
| **캔버스** | **1536 × 1536 정사각** |
| **배경** | 투명 아님 — **꽉 채운다.** 벽도 바닥도 끝까지 |
| **벽·바닥 경계** | 위에서 **60~68%** |
| **발바닥이 닿는 선** | 위에서 **89%** (y ≈ 1368) |
| **비워둘 자리** | 가운데 **폭 50%**(768px), 위에서 **7%부터 89%까지** |
| **그림체** | 곰돌이보다 **연하게.** 크레용 질감, 갈색 외곽선 |

앱에 담길 때 **1000 × 1000으로 줄어든다.** 1536으로 그리는 것은 줄일 여유를 두는 것이다.

---

## 곰돌이가 어디에 서나

발바닥은 늘 같은 자리(위에서 89%)에 닿는다. **옷에 따라 위로만 자란다.**

| | 위에서 | 1536px 기준 |
|---|---|---|
| 제일 큰 옷의 끝 | **0%** | 0 |
| 곰토끼 머리끝 (귀가 제일 길다) | **7%** | 106 |
| 마법사 곰 고깔 끝 | **19%** | 293 |
| 기본 곰돌이 머리끝 | **31%** | 480 |
| **발바닥** | **89%** | **1368** |

가로는 가운데 정렬이고, 제일 넓은 옷(곰토끼)이 **폭 50%**(768px)를 쓴다.

```
1536 × 1536
┌────────────────────────────────┐ 0
│          ↑ 모자·귀 자리         │
│      ┌──────────┐              │ 106   곰토끼 머리끝
│      │          │              │ 293   마법사 고깔
│  벽  │  비워둘   │              │ 480   기본 곰 머리끝
│      │   자리    │              │
├──────│  768px   │──────────────┤ ~980  벽·바닥 경계 (64%)
│ 바닥 │  가운데   │              │
│      └──────────┘              │ 1368  발바닥 ★
│                                │
└────────────────────────────────┘ 1536
```

## 그릴 때 다섯

- **정사각으로 그린다.** 정사각이 아니면 **위가 잘린다**(아래를 맞춰 자른다).
  바닥이 잘리면 곰돌이가 벽에 붙어 선다
- **가운데 폭 50%를 비운다.** 가구·화분·액자는 좌우 25%씩에 놓는다.
  가운데에 큰 것을 놓으면 곰돌이 배에 겹친다
- **벽·바닥 경계를 위에서 60~68%에.** 발바닥이 89%에 닿으니 그 아래로 바닥이
  넉넉히 있어야 **밟고 선 것**으로 보인다. 지금 방은 63%다
- **곰돌이보다 연하게.** 소품이 진하면 눈이 곰돌이를 못 찾는다
- **잔 무늬는 넣지 않는다.** 상점 격자에서 **103px**로 줄어 뜨는데,
  거기서 잔 무늬는 얼룩으로 뭉갠다

> **오른쪽 위를 비우던 규칙은 없어졌다.** 한때 `오늘 할 일 2/5`가 그림 위에 얹혀서
> 오른쪽 위 45%×35%를 비우라고 했는데, 그 숫자가 **그림 밖 아랫줄로 내려갔다**
> ([RoomCard](../../src/screens/home/RoomCard.tsx)). 이제 위쪽도 다 쓸 수 있다.

## ChatGPT에 붙일 말

> 정사각 1536 × 1536 그림 하나를 그려줘. **방 안 풍경**이야.
>
> 크레용 질감의 손그림, 갈색 외곽선, 파스텔 톤. 배경을 꽉 채워서 그려줘 (투명 아님).
>
> **아주 중요한 것** — 그림 **가운데 세로 띠(폭 50%)를 비워둬야 해.**
> 거기에 곰돌이 캐릭터가 따로 얹혀. 위에서 7% 지점부터 89% 지점까지가
> 그 띠의 높이야. 가운데에는 큰 물건을 놓지 말고, 가구·화분·액자 같은 것은
> **좌우 양쪽 25%씩**에 놓아줘.
>
> **벽과 바닥이 만나는 선은 위에서 62% 자리**에. 그 아래는 바닥(나무 마루나 러그),
> 그 위는 벽이야. 곰돌이가 위에서 89% 자리에 발을 딛고 서니까 바닥이 넉넉해야 해.
>
> 색은 **연하게.** 곰돌이가 주인공이라 배경이 튀면 안 돼.
> 잔 무늬나 자잘한 디테일은 넣지 마 — 작게 줄여도 보여야 해.
>
> 글씨나 말풍선은 넣지 마.

방을 여러 개 그릴 거면 **`벽과 바닥이 만나는 선은 위에서 62%`만 그대로 두고**
벽지·바닥재·소품만 바꾸면 된다. 그 선이 움직이면 방마다 곰돌이 발밑이 달라진다.

## 넣는 법

1. 원본을 `assets/shop/deco/room/background/`에 둔다
2. 앱에서 **설정 → 상점 채우기 → ＋ 채우기**
3. 종류 `배경 — 방`, 중분류 `룸`, 이름·값을 적고 그림을 고른다
4. 미리보기로 보고 **저장하고 팔기**

배경은 크기를 맞출 것이 없다 — **정사각 한 장을 통째로 쓴다.**
곰돌이만 자에 맞춘다([곰 맞추기](../곰-맞추기.html)).

## 숫자가 어디서 나왔나

셋을 곱해서 낸 것이다.

| 어디 | 무엇 |
|---|---|
| [src/lib/stage.ts](../../src/lib/stage.ts) | 곰 칸이 방 폭의 몇 %인가(`BEAR_W` 92), 바닥에서 몇 %인가(`BEAR_FLOOR` 8) |
| [src/lib/fit.ts](../../src/lib/fit.ts) | 곰 그림 한 장이 정사각 **760**이다(`BODY`) |
| `public/gomdori/front.png` | 그 760 안에서 기본 곰의 몸이 **343 × 478**, 발바닥이 **y 736** |

발바닥 선 = `(1 − 0.08) − 0.92 + (736 ÷ 760) × 0.92` = **0.891**

**앱의 저 두 값을 고치면 이 문서도 다시 재야 한다.** 재는 것은
`design/곰-맞추기.html`을 다시 뽑으면 눈으로 보이고, 숫자는 위 식으로 낸다.
