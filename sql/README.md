# sql

**이미 돌아가고 있는 DB에 얹는 것들.** 날짜 순서대로 한 번씩 돌린다.

[`../supabase/schema.sql`](../supabase/schema.sql)이 늘 **지금의 온전한 모양**이다.
빈 DB를 새로 세울 때는 여기 있는 것을 순서대로 돌리는 게 아니라 그 파일 하나를 돌리면 된다.

여기 있는 파일은 **이미 쓰고 있는 DB를 그 모양까지 끌어올리는 길**이다.
표를 지우고 다시 만들 수 없으니 따로 있는 것이고, 그래서 둘 다 손봐야 한다 —
`schema.sql`에 고쳐 넣고, 같은 것을 얹는 파일로 여기 하나 더 둔다.

## 규칙

- **두 번 돌려도 되게 쓴다.** `if not exists` · `create or replace` · 돌리기 전에 상태를 보는 조건.
  어디까지 돌렸는지 기억해야 하는 파일은 언젠가 반쯤 돌아간 DB를 만든다
- 파일 하나가 한 덩이의 일이다. 이름은 `날짜_무엇`
- 무엇을 왜 바꾸는지 주석으로 남긴다. `schema.sql`과 같은 말투로
