# 구매 기록 · 자주 사는 것

"우유 언제 샀지?"에 답하는 자리.

---

## 지난 장보기

목록 맨 아래 접힌 채로. 펼치면 **날짜별로 묶여** 있다.

```
지난 장보기 12개 보기 ▾

  오늘                        3
  [우유] [계란] [휴지]

  8월 2일 토요일               2
  [세제] [물티슈]
```

체크할 때 `boughtOn`이 찍히고, 다음 날 저절로 여기로 내려온다.
지우는 게 아니라 옮기는 거라 나중에 언제 샀는지 볼 수 있다.

**항목을 누르면 다시 담긴다.** 이때 지난 기록은 지워지지 않고 새 줄이 생긴다 —
우유를 다섯 번 샀으면 다섯 번이 남아야 하니까.

## 자주 사는 것

입력 줄 밑에 칩으로 자동으로 올라온다.

```
[우유 3]  [계란 2]  [휴지 2]
```

- **두 번 이상 산 것**만 올라온다. 산 횟수도 같이 보여준다
- 이미 목록에 있는 건 빠진다
- 누르면 한 번에 담긴다. **메모·구입처도 같이 딸려온다** —
  늘 쿠팡에서 저지방 우유를 산다면 매번 다시 적을 일이 없다

할 일 쪽 `자주 쓰는 일`과 같은 구조지만, **여기는 등록할 필요가 없다.**
산 기록에서 저절로 뽑힌다. 장보기는 같은 걸 반복해서 사니까 그게 자연스럽다.
