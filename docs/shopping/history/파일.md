# 구매 기록 — 파일

| 파일 | 하는 일 |
|---|---|
| `src/screens/shop/ShopHistory.tsx` | 지난 장보기. 날짜별로 묶고, 눌러 다시 담기 |
| `src/screens/shop/FrequentChips.tsx` | 자주 사는 것 칩. 두 번 이상 산 것을 셈해서 뽑는다 |
| `src/lib/store.tsx` | `rebuyShopItem(id)` — 기록은 두고 같은 이름으로 새로 담는다 |
| `src/lib/selectors.ts` | `onShopList` — 기록은 이걸 뒤집은 것 |
| `src/components/ScrollRow.tsx` | 칩이 넘칠 때 끝을 흐린다 |

## 셈하는 법

```
history = 담았고 boughtOn이 오늘이 아닌 것
자주 사는 것 = history를 제목으로 묶어 2회 이상, 이미 목록에 있는 건 뺀다
```

칩의 `id`는 **가장 최근 것**을 가리킨다. 다시 담을 때 최근 메모·구입처가 따라오게.

## 조심할 것

- 다시 담기는 **새 항목을 만든다.** 기록을 되살리는 게 아니다.
  살 때마다 한 줄씩 쌓여야 "언제 샀는지"가 남는다
- 같은 이름이 이미 목록에 있으면 안 담고 알려준다
