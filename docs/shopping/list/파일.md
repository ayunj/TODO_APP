## 가르는 규칙

```ts
onShopList(item, today) = !item.done || item.boughtOn === today
```

한 줄이 전부다. 화면과 스토어가 같은 걸 쓴다.

## 조심할 것

- **날짜·주기·카테고리를 넣지 않는다.** 넣고 싶어지면 [기능.md](기능.md)를 먼저 읽는다
- 입력 칸 포커스 테두리는 `outline-offset: -2px`.
  바깥으로 그리면 고정 헤더에 덮여 윗변이 잘린다 (한 번 겪었다)
- `roomId`는 **하나뿐이다.** 여럿에 걸리는 건 메모뿐이고 그건 `room_ids`를 따로 쓴다
- 방 칩 줄은 `settleScope()`를 지난 값을 쓴다 — 방에서 나왔거나 장보기를 끈 참이면
  없는 칸을 계속 보고 있지 않게 `전체`로 돌아간다
- `doneBy` 칸은 뚫어놨지만 아직 늘 `null`이다
