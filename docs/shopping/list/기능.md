# 장보기 목록

집에 필요한 걸 떠오를 때 적어두고, 마트에서 하나씩 지운다.

---

## 할 일과 같은 서랍에 넣지 않았다

**`우유`는 할 일이 아니다.**

날짜를 붙이면 안 산 우유가 `3일 지남`으로 뜬다. 그건 밀린 일이 아니라 아직 안 산 것뿐이다.
밀린 일을 다그치지 않는다는 이 앱의 원칙을 스스로 어기는 셈이 된다.

그래서 **날짜·주기·우선순위·카테고리가 전부 없다.** 평평한 목록 하나다.

## 탭이 아니라 밀고 들어간다

메인은 할 일이다. 장보기가 탭 한 칸을 차지할 만큼 자주 여는 화면은 아니다.

**헤더의 장바구니 아이콘**으로 들어간다. 들어가면 탭바와 + 버튼이 사라지고
왼쪽 위에 뒤로가기 화살표가 생긴다. 나오면 들어가기 전에 보던 탭으로 돌아간다.

숨기기만 하면 목록의 존재를 잊으니, **담아둔 개수를 배지로 띄운다.**

## 적기

위에 입력 줄이 **늘 떠 있다.** `우유` 엔터 → `계란` 엔터 → `휴지` 엔터.
포커스가 남아 있어서 떠오르는 대로 이어 적힌다.

시트를 띄우면 다섯 개 적을 때 다섯 번 열어야 한다. 그래서 + 버튼도 여기선 감춘다.

## 한 줄

```
☐  우유                            ×    ← 삭제
   ┌ 저지방으로 2개 ┐        ← 메모
   [쿠팡]  08.04 담음        ← 구입처 배지 + 산 날
```

이름을 누르면 **이름 / 어디서 / 메모** 시트가 열린다.

**×는 할 일 한 줄과 같은 자리에 있다.** 한동안 여기만 없어서 안 살 것을 빼려면
시트를 열어 맨 아래까지 내려가야 했다. 지운 것은 30일 남는다 —
화면 맨 아래 `지운 것`에서 되돌린다.
구입처는 전에 적은 곳이 자동완성으로 뜬다 — `쿠팡`을 매번 다시 칠 일이 없다.

## 방과 나누기 — 한 곳만

방을 쓰면 맨 위에 **방 칩 줄**이 붙는다. 나눌 방이 없으면 이 줄은 아예 없다.

```
[전체] [나만] │ [집 👥] [회사 👥]
[ 집에 살 것 적기        ] [+]     ← 고른 자리가 적는 칸에 적힌다

☐  우유                     [집]   ← 제목 줄 오른쪽에 방 칩
☐  내 영양제                       ← 칩이 없으면 나만 보는 것
```

- **기본은 `전체`다.** 마트에서는 집 것 회사 것 가리지 않고 그냥 훑는다.
  가려 보는 건 담을 때나 계산할 때 하는 일이다
- **고른 자리에 담긴다.** 집 칩을 눌러두면 적는 칸이 `집에 살 것 적기`로 바뀐다 —
  담고 나서 어디 갔는지 찾게 하지 않는다
- **한 곳만 고른다.** 두 곳에 필요하면 두 번 적는다. 어차피 따로 사야 하고,
  하나를 담았다고 저쪽이 지워지면 안 된다
- 시트에서 **공유는 접혀 있다.** 담는 대부분이 개인 것이라 아무것도 안 묻는다.
  `＋ 공유`를 눌러야 `어디에` 칩이 펴진다. 이미 방에 있는 것은 펴서 보여준다
- **장보기를 끈 방은 아예 안 뜬다.** 고를 수 없으니 잘못 누를 수 없다
- 다시 담기(자주 담는 칩)는 **그 항목이 있던 자리로** 되돌아간다

## 목록과 기록이 갈리는 규칙 — 딱 하나

> **오늘 담은 것까지는 목록에 남고, 그 전에 담은 것은 다음 날 저절로 기록으로 내려간다.**

체크하면 그 순간 이미 기록된다. 누를 게 없다.

오늘 담은 건 아래에 `오늘 담음 3`으로 남는다 — 마트 도는 동안 "이거 담았나?" 확인이 돼야 하니까.
다음에 열면 알아서 `지난 장보기`로 내려가 있다.

예전엔 `장보기 끝내기` 버튼이 있었는데, **무슨 뜻인지 물어봐야 아는 버튼이었다.**
이름을 고치는 대신 버튼 자체를 없앴다. 보관 상태를 따로 저장하지 않고
`boughtOn` 날짜 하나로 판단하니 어긋날 것도 없다.
