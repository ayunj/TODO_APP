## 어디에 뜨나 — scope 하나로

```ts
pushView({ kind: 'trash', scope: 'room',     id: room.id });  // 방 설정
pushView({ kind: 'trash', scope: 'category', id: cat.id });   // 카테고리 설정
pushView({ kind: 'trash', scope: 'shop',     id: '' });       // 장보기 맨 아래
pushView({ kind: 'trash', scope: 'memo',     id: '' });       // 메모 맨 아래
```

`room`일 때만 카테고리 칩과 지운 사람 이름이 붙는다. 나머지는 날짜뿐이다.

## 두 가지 지움

```ts
remove(id)          // 사람이 지운 것 — deleted_by가 붙고 30일 남는다
purge(bucket, ids)  // 그냥 없앤 것 — 이 기기 디스크에서만 지운다
```

**뒷정리에는 `purge`를 쓴다.** 다음 회차 정리·전체 초기화·30일 지난 것.
`remove`를 쓰면 `지운 것`이 그걸로 다 찬다.

## 조심할 것

- **되돌리기는 `deleted_at`을 지우는 것이다.** 새로 만들지 않는다 —
  새로 만들면 오늘 날짜로 되살아나서 지난달에 지운 게 이번 달 격자에 뜬다
- **30일 청소는 서버에 알리지 않는다.** 알리면 `updated_at`이 오늘로 밀려서
  그 줄이 영영 안 늙고 다음 동기화에 또 내려온다
- **목록을 그리는 곳은 `alive`로 거른다.** `deleted_at`이 붙은 줄이 화면에 남으면
  지운 게 안 지워진 것처럼 보인다
- 방 것과 개인 것을 `roomId`로 가른다. 공유 카테고리에서 지운 것은
  카테고리 설정이 아니라 **방 설정**에 모인다
