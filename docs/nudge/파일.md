## 값이 흐르는 길

```
콕 누름 → send_nudge(room, task, whom)      ← 세는 것도 넣는 것도 서버가 한다
             ├ 마지막 아침 6시를 지났으면 3으로 채운다
             ├ 0이면 못 보낸다
             ├ nudges에 한 줄씩 (담당자 한 명 또는 방 전체)
             └ nudge_left − 1  → 남은 횟수를 돌려준다

앱 열기 → pullNudges() → 띠 → 닫으면 clearNudges()
```

## 조심할 것

- **넣는 길은 `send_nudge()` 하나뿐이다.** `nudges`에 insert 정책을 열면 한도가 뜻을 잃는다
- **`nudges_left()`는 읽기만 한다.** 보기만 했는데 채워지면 그게 배치다
- **`last_refill()`은 `오늘 6시`가 아니라 `마지막 6시`다.** 새벽 3시에 오늘 6시를 기준으로 삼으면
  새벽마다 한 번씩 더 채워진다
- **자르는 기준은 `Asia/Seoul`.** UTC로 세면 하루가 엉뚱한 때 바뀐다
- **한 번 찌르면 한 번만 준다.** 방 전체로 나가도 마찬가지다
- 차례 칩 지름길은 **눌림을 멈춰 세운다**(`stopPropagation`). 안 그러면 줄 전체의 `수정`이 같이 열린다
