## 저장 방식

화면 → 목록 상태 → 디스크 순으로 간다.

글자 하나마다 디스크에 쓰지는 않지만(600ms 쉬면 쓴다) **목록 상태는 늘 최신**이다.
그래서 다 적기 전에 바로 `새 메모`를 눌러도 방금 쓴 게 안 사라진다.

지울 때는 **대기 중인 저장도 같이 취소**한다. 안 그러면 지운 메모가 되살아난다.

## 안 본 표시

```
안 본 것 있음 = memos.some(m => m.text.trim() && m.updatedAt > memoSeenAt)
```

`memoSeenAt`은 메모 화면에 **들어올 때와 나갈 때** 찍는다.

## 조심할 것

- 카드를 `key={memo.id}`로 그린다. 다른 장을 펼칠 때 입력 상태가 섞이지 않게
- 펼친 카드의 테두리도 `outline-offset: -2px` (바깥으로 그리면 잘린다)
- 한 장짜리로 쓰던 시절 데이터에는 `createdAt`이 없다. 불러올 때 `updatedAt`으로 채운다
