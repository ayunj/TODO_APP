## 값이 흐르는 길

```
앱 켜짐 → pullNotice()          ← 로그인과 상관없다
            켜진 것 중 제일 새것 하나
        → shouldShow(notice)     폰에 담아둔 것과 견준다
            판이 다르면 → 띄운다  (고쳐 올린 공지는 새 공지)
            그 날이 지났으면 → 띄운다
        → 팝업

오늘 다시 열지 않기 → hushToday()  폰에 `{판, 그 날}`을 담는다
닫기               → 아무것도 안 담는다. 앱을 다시 켜면 또 뜬다

설정 → 공지 → 목록
        스위치 → setNoticeActive(id, true)
                   나머지를 내리고 → 이것을 켠다
        카드   → 쓰는 자리 (제목 · 내용 · 이렇게 떠요)
```

## 조심할 것

- **띄우는 것은 하나뿐이다.** 켤 때 나머지를 내린다 — 여럿 켜두면 목록에서
  어느 것이 뜨는지 알 수가 없다
- **새로 쓴 것은 안 띄우고 들어온다.** 켜야 뜬다
- **폰을 못 읽으면 띄운다.** 시크릿 창·저장을 막아둔 설정에서 `localStorage`는
  만지는 것만으로 던진다 — 그때는 담아둔 것이 없는 것으로 친다.
  **한 번 더 뜨는 것은 잘못이 아니다**
- **판은 `updated_at`이다.** 글을 고치면 눌러둔 것이 무른다
- **RLS가 막으면 오류가 안 난다.** `0줄 고쳤다`로 지나가니 고친 줄이 돌아오는지 본다
- **묻는 말보다 z가 낮다.** 늦게 도착한 공지가 묻는 말의 단추를 덮으면 안 된다
