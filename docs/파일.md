# 파일이 하는 일

어디를 고쳐야 하는지 찾는 지도.
★ 표시는 건드리기 전에 한 번 더 생각할 곳이다.

---

## 층이 나뉜 방향

```
화면(screens, sheets, components)
      ↓  useStore() / useUi() / useAuth()
상태(lib/store.tsx, lib/ui.tsx, lib/auth.tsx)
      ↓  Repository 인터페이스
저장(lib/repo/*)  ──  로컬(IndexedDB)  +  서버(Supabase)
```

**화면은 저장소를 직접 부르지 않는다.** 늘 스토어를 지난다.
**스토어는 Supabase를 모른다.** `Repository` 인터페이스만 본다.

## src/lib — 규칙과 상태

| 파일 | 하는 일 |
|---|---|
| `types.ts` | `Task` `Preset` `Category` `ShopItem` `Memo` `Settings` `Grave` |
| `date.ts` | ★ 날짜는 앱 전체에서 `'YYYY-MM-DD'` **문자열로만** 다룬다. `Date` 객체는 이 파일 안에서만 산다 |
| `repeat.ts` | ★ **이 앱의 핵심.** `baseOf` `spawnNext` `cycleProgress` |
| `repeat.test.ts` | 반복 주기 필수 3케이스. `npm test` |
| `selectors.ts` | 날짜·월별 조회, 기록 격자 행 만들기, `onShopList`(장보기 목록/기록 가르는 한 줄) |
| `constants.ts` | 팔레트 10색, 카테고리 틴트, 기본 카테고리 둘, 지난 팔레트 옮김표 |
| `store.tsx` | ★ 모든 데이터와 쓰기 동작. 낙관적 업데이트(화면 먼저, 저장은 뒤에) |
| `ui.tsx` | 지금 보는 탭·날짜·필터·열린 시트. `pushView`/`popView`(장보기·메모) |
| `auth.tsx` | 세션, 이메일 로그인·가입, 익명 로그인, 비밀번호 재설정. Supabase 영어 오류를 한글로 |
| `supabase.ts` | 클라이언트를 **쓸 때 가서 받아온다**. 위에서 그냥 import하면 60KB가 열쇠 없는 사람에게도 실린다 |
| `id.ts` | uuid 만들기. 서버 컬럼이 uuid라 그대로 올릴 수 있어야 한다 |
| `toast.ts` | 어느 층에서든 부를 수 있는 알림 |

### src/lib/repo — 저장소

| 파일 | 하는 일 |
|---|---|
| `../repository.ts` | ★ **데이터 접근 인터페이스.** 이 한 겹만 지난다 |
| `index.ts` | `getRepository(owner)` — 로그인 전엔 로컬, 후엔 감싼 것 |
| `indexeddb.ts` | 1단계 저장소. DB `todolist` v5 (categories·tasks·presets·shopping·memo·settings·graveyard) |
| `memory.ts` | SSR·테스트용. IndexedDB 없는 곳에서 앱이 안 죽게 |
| `remote.ts` | 서버 한 겹. 카멜케이스 ↔ 스네이크케이스 변환, `pull`/`push`/`drop` |
| `synced.ts` | ★ **로컬을 감싸 서버와 맞춘다.** 합치기 규칙, 무덤 비우기, id 옮기기, 주인 바뀜 처리 |

## 그 밖

| 파일 | 하는 일 |
|---|---|
| `supabase/schema.sql` | ★ 테이블·RLS·`create_room`·`join_room`. 대시보드 SQL Editor에 붙여넣는다 |
| `public/sw.js` | 서비스워커. 앱 껍데기만 캐시하고 **데이터는 안 건드린다** |
| `public/manifest.webmanifest` | PWA 이름·색·아이콘 |
| `scripts/make-icons.mjs` | `npm run icons` — 강조색 바뀔 때 아이콘 다시 뽑기 |
| `tailwind.config.ts` | 색을 CSS 변수로 잇는다. `--accent`는 고정 |
| `.env.example` | 열쇠 견본. 실제 값은 `.env.local`(git에 안 올라감) |
