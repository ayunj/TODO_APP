# 상점 채우기 — 파일

| 파일 | 하는 일 |
|---|---|
| `supabase/schema.sql` | ★ `costume_catalog`의 칸 다섯 · `costume_season` · `shop_admins` · `is_shop_admin()` · Storage `shop` 통 |
| `sql/2026-08-25_곰돌이-포인트-상점.sql` | ★ **이미 도는 DB에 얹는 것.** 곰돌이·포인트·상점을 한 덩이로 |
| `design/관리자.html` | ★ **시안.** 브라우저 판 · 앱 판 · 그대로 띄웠을 때 |
| `src/lib/costumes.ts` | 앱 목록 — 아직 여기가 주인이다 |

**앱 화면은 아직 없다.** 위 표에 `src/screens/` 줄이 없는 까닭이다.

## 표와 칸

```
costume_catalog     item_key  kind  price  season          ← 있던 것
                  + name  img  active  created_at  updated_at
                  + family                          꾸미기 · 코스튬 (시즌 줄에는 안 단다)

costume_season      season_key  name  ord  note  created_at
shop_admins         user_id  added_at
storage:shop        shop/<코드>.png
```

## 누가 무엇을 할 수 있나

| | 손님 | 관리자 |
|---|---|---|
| 값표 읽기 | `active`인 것만 | **숨김까지 전부** |
| 값표 넣기·고치기 | ✕ | ○ |
| 값표 지우기 | ✕ | **✕ — 아무도 못 한다** |
| 세트 이름표 읽기 | ○ | ○ |
| 세트 이름표 넣기·고치기 | ✕ | ○ |
| 관리자 명단 | 자기 줄만 | 자기 줄만 |
| 그림 보기 | ○ | ○ |
| 그림 올리기 | ✕ | ○ |

관리자 명단에 **넣고 빼는 정책은 없다.** SQL Editor에서 손으로 하는 일이다.

## 조심할 것

- **`is_shop_admin()`은 `security definer`다.** 정책 안에서 `shop_admins`를 그냥 읽으면
  그 표의 정책이 다시 불린다 — `is_member`와 같은 까닭이다
- **씨앗은 `do nothing`에 가깝다.** 부딪히면 이름이 빈 줄만 채워 켠다.
  `do update`로 되돌리면 관리자가 고쳐놓은 값이 `schema.sql`을 돌릴 때마다 날아간다
- **`active` 기본값이 `false`다.** 관리자가 넣은 줄은 숨김으로 들어온다.
  `schema.sql`이 새로 심는 것도 마찬가지다 — 그림이 없는 채로 상점에 뜨면 안 된다
- **`family`도 한 번만 정해준다**(`where family is null`). 덮으면 관리자가 옮겨둔 갈래가
  `schema.sql`을 돌릴 때마다 되돌아간다
- **`buy_costume`도 `active`를 본다.** 상점에 안 떠도 열쇠만 알면 부를 수 있는 자리다
- **`grant_poses`는 소품 아닌 것이 하나라도 있는 시즌만 연다.**
  이 줄이 없으면 소품만 올려둔 새 세트가 `다 모았다`로 읽혀 모두에게 들어간다
- **숨김이 된 곰·방도 세트 조건에 그대로 센다.** 빼면 하나 숨기는 순간 세트가 거저 열린다
- **`my_points()`가 `grant_poses()`도 부른다.** 살 때만 보면 숨겼던 소품을 켠 뒤
  뭔가 하나 더 사기 전까지 안 온다
- **Storage 블록은 막혀도 안 멈춘다.** 우리 표가 아니라 Supabase 것이라 권한이
  모자랄 수 있어서, `insufficient_privilege`면 `notice`만 남기고 넘어간다.
  그때는 대시보드에서 통을 손으로 만든다(public)
- **파일 이름은 코드 그대로다**(`shop/<코드>.png`). 다르게 두면 대조표가 하나 더 생긴다

## 돌리는 법

빈 DB면 `supabase/schema.sql` 하나, 이미 도는 DB면
`sql/2026-08-25_곰돌이-포인트-상점.sql` 하나. 둘 다 두 번 돌려도 된다.
자세한 것은 [database](../../account/database/기능.md).

돌린 뒤 **관리자를 손으로 하나 넣어야** 채울 수 있다.
