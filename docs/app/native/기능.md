# 안드로이드 앱

같은 코드로 **웹과 앱을 둘 다** 낸다. Capacitor가 `out/`을 네이티브 껍데기에 담는다.

- 웹 — **https://everyeight.vercel.app** (지금까지대로)
- 앱 — APK를 폰에 직접 설치. 스토어는 나중에

---

## 왜 Capacitor인가

| | |
|---|---|
| **Capacitor** ← 이걸 쓴다 | `out/`을 통째로 기기에 담는다. 서버를 안 본다. 스토어에 올라가고 네이티브 알림을 붙일 수 있다 |
| TWA (Bubblewrap) | 실체는 크롬이 URL을 여는 것. 작업은 적지만 지금 PWA와 크게 다르지 않다 |
| React Native · Flutter | 전부 다시 쓴다. 할 이유가 없다 |

**화면 코드는 한 줄도 안 고쳤다.** 서버 코드가 처음부터 없어서 정적 내보내기가 그대로 됐다.
데이터는 이미 IndexedDB를 먼저 보기 때문에 비행기 모드에서도 그대로 돈다 —
껍데기만 바뀌었지 앱이 도는 방식은 웹과 같다.

## 웹 빌드와 갈라뒀다

```bash
npm run build      # 웹 — Vercel. .next/ 만 만든다
npm run app:build  # 앱 — out/ 을 만들고 android/ 로 밀어넣는다
```

`next.config.mjs`가 `BUILD_TARGET=app`일 때만 `output: 'export'`를 켠다.
서버 코드가 없어서 둘 다 같은 결과가 나오지만, **앱을 붙이면서 웹 배포를 건드리고 싶지 않아서** 갈라뒀다.

## 서비스워커는 앱에서 등록하지 않는다

껍데기는 `http://localhost`로 뜨고 파일은 이미 기기에 들어 있다. 캐시할 게 없다.
그대로 두면 옛 캐시가 껴서 고친 게 안 보인다. `providers.tsx`에서 `'Capacitor' in window`로 걸러낸다.

## APK 굽기

**필요한 것** — JDK 17(있음)과 **Android SDK**. Android Studio를 깔면 같이 온다.

```bash
npm run app:build   # 웹 자산을 android/ 로 밀어넣는다. 고칠 때마다 먼저 돌린다
npm run app:open    # Android Studio에서 열기
```

Android Studio에서 `Build → Build Bundle(s) / APK(s) → Build APK(s)`.
나온 파일은 `android/app/build/outputs/apk/debug/app-debug.apk`.

Studio 없이 SDK만 있으면:

```bash
cd android && ./gradlew assembleDebug
```

**폰에 넣기** — APK를 옮기고 열면 `알 수 없는 출처` 허용을 묻는다. 허용하면 설치된다.

## 아이콘과 스플래시

```bash
npm run icons                              # 원본 넷을 assets/ 에 뽑고
npx @capacitor/assets generate --android   # 모든 밀도로 펼친다
```

`scripts/make-icons.mjs`의 `BRAND` 하나만 바꾸면 웹·앱 아이콘이 다 새로 나온다.
앱 아이콘은 **모서리를 안 깎는다** — 런처가 기기 모양대로 잘라내서 미리 깎으면 두 번 깎인다.

## 스토어에 올릴 때

아직 안 했다. 그때 필요한 것만 적어둔다.

- **`appId`는 한 번 올리면 못 바꾼다.** `app.everyeight.todo`로 박아뒀다
- **릴리스 서명키.** 디버그 APK는 디버그 키로 서명된다. 스토어용은 따로 만들어야 하고,
  **잃어버리면 그 앱을 영영 업데이트 못 한다.** 키스토어 파일과 비밀번호를 잘 둬야 한다
- 개발자 등록 $25 (1회), 스토어 등록 정보(설명·스크린샷·개인정보처리방침)

## 알아둘 것

**비밀번호 재설정 메일의 링크는 웹으로 열린다.** Supabase의 `Site URL`이 웹 주소라서다.
웹을 계속 두기로 했으니 문제는 아니다 — 웹에서 새 비밀번호를 정하고 앱에서 로그인하면 된다.
앱 안에서 끝내려면 딥링크를 붙여야 한다.

**계정으로 로그인하면 웹과 앱이 같은 목록을 본다.** 같은 Supabase를 보기 때문이다.
로그인 안 한 상태에서는 각자 자기 기기 것만 본다 — 웹과 앱은 저장소가 따로다.

**고칠 때마다 `npm run app:build`를 돌려야 폰에 반영된다.** 웹처럼 새로고침으로 되지 않는다.
파일이 APK 안에 들어 있어서 다시 설치해야 한다.
