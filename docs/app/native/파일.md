# 안드로이드 앱 — 파일

| 파일 | 하는 일 |
|---|---|
| `capacitor.config.ts` | `appId` · 앱 이름 · `webDir: 'out'` · 바탕색 |
| `next.config.mjs` | `BUILD_TARGET=app`일 때만 `output: 'export'` |
| `package.json` | `app:build`(밀어넣기) · `app:apk`(굽기) · `app:open`(Studio) |
| `scripts/make-icons.mjs` | 웹 아이콘 넷 + 앱 원본 넷(`assets/`) |
| `scripts/apk.mjs` | gradlew 래퍼를 셸 안 거치고 직접 부른다 |
| `android/build.gradle` | 자바 21 툴체인 (경로를 안 박는다) |
| `android/local.properties` | SDK 경로. **커밋 안 됨** — 기기마다 다르다 |
| `assets/` | `icon` `icon-foreground` `icon-background` `splash` — 펼치기 전 원본 |
| `android/` | 네이티브 프로젝트. 커밋한다 |
| `src/app/providers.tsx` | 앱 안에서는 서비스워커를 등록하지 않는다 |

## 명령

```bash
npm run app:apk     # 내보내기 → 밀어넣기 → APK 까지 한 방에
npm run app:build   # next build(export) + cap sync android 까지만
npm run app:open    # Android Studio
npm run icons       # 아이콘 원본 다시 뽑기
```

## 조심할 것

- **`npm run build`(웹)는 `out/`을 만들지 않는다.** 갈라놨기 때문이다.
  앱을 밀어넣기 전에는 반드시 `app:build`를 쓴다
- **`android/app/src/main/assets/public`은 빌드 산출물이다.**
  Capacitor가 만든 `android/.gitignore`가 이미 걸러낸다. 손으로 고치지 않는다
- **`appId`를 바꾸면 다른 앱이 된다.** 폰에 두 개가 따로 깔리고, 스토어에 올린 뒤에는 못 바꾼다
- `assets/`의 원본을 고쳤으면 `npx @capacitor/assets generate --android`를 다시 돌려야
  `android/`의 밀도별 파일이 갱신된다. `app:build`는 아이콘을 안 건드린다
- 서명키(릴리스)는 **저장소에 넣지 않는다.** `.gitignore`의 `.env*`와 같은 이유다
- **`.bat`은 Node가 `shell` 없이 실행하지 못한다.** `spawnSync`의 `error`를 안 보면
  아무 말 없이 실패해서 한참 헤맨다 (한 번 걸렸다)
- 자바 21이 없는 PC에서는 `No matching toolchains found`로 실패한다. JDK를 깔면 된다
