# PWA — 홈 화면 설치

폰 홈 화면에 아이콘으로 두고, 열면 주소창 없이 전체 화면.

**https://everyeight.vercel.app**

---

## 설치

안드로이드 크롬으로 열고 **⋮ → 앱 설치**. 배너가 뜨기도 한다.

설치가 되려면 이게 다 있어야 한다:

| 조건 | 상태 |
|---|---|
| HTTPS | Vercel이 준다 |
| 매니페스트 (이름 · `display: standalone`) | ✓ |
| **192px · 512px PNG 아이콘** | ✓ 없으면 설치 항목이 안 뜬다 |
| 서비스워커 | ✓ 운영에서만 등록 |

**같은 와이파이로 `http://192.168.x.x:3000`에 붙으면 설치가 안 된다.**
서비스워커가 등록되지 않아서 조건을 못 채운다. 화면 구경은 되지만 앱으로는 안 열린다.

## 아이콘

`npm run icons`로 뽑는다. 강조색이 바뀌면 다시 돌린다.

| 파일 | 무엇 |
|---|---|
| `icon-192.png` `icon-512.png` | 설치용 |
| `icon-maskable-512.png` | **안드로이드가 원형·물방울로 잘라내도 살아남게** 안쪽 70%에만 그린다 |
| `apple-touch-icon.png` | iOS용. 180px, 모서리를 안 깎는다 (iOS가 알아서 둥글린다) |
| `icon.svg` | 브라우저 탭 |

**iOS는 매니페스트의 아이콘을 보지 않는다.** `apple-touch-icon`이 없으면
홈 화면에 페이지 스크린샷이 박힌다.

## 오프라인

서비스워커는 **앱 껍데기만** 캐시한다. 네트워크 우선, 끊기면 캐시.

**데이터는 안 건드린다.** 그건 IndexedDB 담당이다.
화면이 늘 로컬을 보기 때문에 비행기 모드에서도 체크가 된다.

## safe-area

iOS 노치와 홈 인디케이터를 피한다. 탭바·+ 버튼·헤더·시트에 `env(safe-area-inset-*)`.

`viewportFit: 'cover'`가 layout에 있어야 이게 동작한다.

## 새 버전이 안 보일 때

앱을 완전히 닫았다 다시 연다. 서비스워커가 네트워크 우선이라 보통은 바로 반영된다.

`sw.js`를 고쳤으면 `CACHE` 이름의 버전을 올린다. 그래야 옛 캐시가 정리된다.
