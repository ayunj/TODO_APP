# PWA — 파일

| 파일 | 하는 일 |
|---|---|
| `public/manifest.webmanifest` | 이름 · `display: standalone` · 배경/테마색 · 아이콘 목록 |
| `public/sw.js` | 서비스워커. 껍데기만 캐시, 네트워크 우선 |
| `public/icon-192.png` `icon-512.png` | 설치용 |
| `public/icon-maskable-512.png` | 잘려도 살아남게 안쪽 70% |
| `public/apple-touch-icon.png` | iOS 홈 화면 (180px, 모서리 안 깎음) |
| `public/icon.svg` | 브라우저 탭 |
| `scripts/make-icons.mjs` | `npm run icons` — 위 넷을 한 번에 뽑는다 |
| `src/app/layout.tsx` | 매니페스트 연결, `appleWebApp`, `icons`, `viewportFit: 'cover'` |
| `src/app/providers.tsx` | 서비스워커 등록 (**운영에서만**) |

## 아이콘 다시 뽑기

```bash
npm run icons
```

`scripts/make-icons.mjs`의 `BRAND` 상수 하나만 바꾸면 넷이 다 새로 나온다.
색이 세 번 바뀌는 동안 손으로 그리다 지쳐서 스크립트로 뺐다.

## 조심할 것

- **`new URL(...).pathname`은 윈도에서 `/C:/…`가 된다.** sharp가 못 받는다.
  `fileURLToPath()`를 써야 한다 (한 번 걸렸다)
- `sw.js`의 `SHELL` 목록에 없는 주소를 넣으면 **설치가 통째로 실패한다.**
  `cache.addAll`은 하나만 404여도 전부 되돌린다
- `sw.js`를 고치면 `CACHE` 버전을 올린다
- 서비스워커는 운영에서만 등록한다. 개발 중에 캐시가 끼면 고친 게 안 보여서 헤맨다
