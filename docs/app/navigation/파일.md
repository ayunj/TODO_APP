## 밀고 들어가기

```ts
pushView('shop')   // 들어가기 전 탭을 기억해둔다
popView()          // 그 탭으로 돌아간다
```

`ViewKind = 'day' | 'month' | 'log' | 'shop' | 'memo'`.
앞의 셋만 탭바에 있다.

## 시트의 두 문

```tsx
<Sheet title="즐겨찾기"
       onClose={closeSheet}                      // 덮개·Esc — 완전히 닫는다
       onBack={() => openSheet({kind:'settings'})} // 화살표 — 상위로
/>
```

`onBack`을 주면 화살표가 `‹`(뒤로), 안 주면 `⌄`(닫기)가 된다.

## 조심할 것

- **`.wrap`의 아래 여백은 탭바 높이(`--bar`)를 비운 것이다.**
  탭바를 감추는 화면에서는 그만큼 빈 자리가 남는다 (지금은 그냥 둔다)
- 입력 칸을 화면 맨 위에 두면 포커스 테두리가 고정 헤더에 덮인다.
  `outline-offset: -2px`로 안쪽에 그려서 막았다
- 첫 화면·로그인 화면은 `.wrap`을 안 쓴다. 탭바가 없어서 여백 계산이 다르다
