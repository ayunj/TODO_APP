# 알림 — 파일

| 파일 | 하는 일 |
|---|---|
| `src/lib/notify.ts` | ★ 예약·취소·문구. **네이티브를 만지는 유일한 자리** |
| `src/lib/notify.test.ts` | 문구 — 개수 세 갈래와 첫 줄 요약 |
| `src/lib/selectors.ts` | `myTasksOn` — 남의 차례만 뺀다 |
| `src/lib/date.ts` | `atTime` — `'HH:MM'`을 그 날 그 시각으로. **`Date`가 나가는 유일한 자리** |
| `src/lib/store.tsx` | 할 일이 바뀌면 이틀치를 다시 건다 |
| `src/components/AppShell.tsx` | `내일로 미루기` 단추를 받는다 |
| `src/screens/settings/PrefsScreen.tsx` | 켤 때 권한을 묻는다 · 브라우저면 한 줄 |
| `android/app/src/main/AndroidManifest.xml` | 정확 알람 권한을 도로 뺀다 |

## 값이 흐르는 길

```
할 일이 바뀐다 → store의 효과 → reschedule(이틀치)
                                   ↘ 앱이 아니거나 껐거나 권한이 없으면 지우고 끝
```

```ts
// 우리가 건 것만 지운다 — 번호를 갈라 쓴다
idOf('todo', day) = 1000 + day
idOf('left', day) = 2000 + day
```

## 조심할 것

- **`notify.ts`는 스토어를 안 부른다.** 스토어가 이 파일을 부르고 있어서
  서로 부르면 고리가 된다. 단추를 눌렀을 때 무엇을 할지는 `AppShell`이 정한다
- **플러그인은 필요할 때 불러온다**(`await import`). 브라우저 뭉치에 안 섞이게
- **지난 시각은 안 건다.** 걸면 그 자리에서 울린다
- **`exact: false`로 건다.** 매니페스트에서 뺀 권한과 짝이다 — 한쪽만 고치면 어긋난다
