## IndexedDB 스토어 (v5)

```
categories  tasks  presets  shopping  memo   ← 초기화가 비운다
settings  graveyard                          ← 남는다
```

버전을 올릴 일이 생기면 `DB_VERSION`과 `STORES`를 같이 고친다.
`onupgradeneeded`가 빠진 스토어만 만들어준다.

## 조심할 것

- 화면에서 `supabase()`나 `indexedDB`를 직접 부르지 않는다
- 새 데이터 종류는 이 순서로 지난다:
  `types.ts` → `repository.ts` → `repo/indexeddb.ts` → `repo/memory.ts` →
  `repo/remote.ts` → `repo/synced.ts` → `store.tsx`
- `clearAll()`은 데이터만 비운다. `settings`는 남는다 (`onboarded`가 살아 있어야 한다)
