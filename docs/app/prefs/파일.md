# 앱 설정 — 파일

| 파일 | 하는 일 |
|---|---|
| `src/screens/settings/PrefsScreen.tsx` | 주 시작 고르기 · 알림 토글 · 시각 두 줄 |
| `src/lib/store.tsx` | `weekStart` `notify` `notifyTodo` `notifyLeft`와 그 setter |
| `src/lib/types.ts` | `Settings`에 네 칸 |
| `src/lib/repo/indexeddb.ts` · `memory.ts` | 기본값 |
| `src/app/globals.css` | `.time-input` — 브라우저가 다는 시계 그림을 지운다 |

## 어디에 담기나

`Settings`다. **할 일이 아니라 이 기기의 상태**라서 전체 초기화로도 안 지워지고
서버에도 안 올라간다 ([architecture](../architecture/기능.md)).

```ts
const { weekStart, setWeekStart, notify, setNotify, notifyTodo, setNotifyTime } = useStore();
```

`loadSettings()`가 기본값과 합쳐서 돌려주므로 **칸을 더해도 DB 버전을 올릴 필요가 없다.**

## 주 시작을 쓰는 곳

| 파일 | 어떻게 |

| `src/screens/MonthScreen.tsx` | 요일 머리 순서와 앞 빈칸 수 |
| `src/screens/LogScreen.tsx` | 주간이 어느 날부터 일곱 칸인지 |
| `src/components/Header.tsx` | `8월 10일 주` 제목 |
| `src/lib/date.ts` | `weekStartOf(날짜, 주시작)` |

## 조심할 것

- **달력의 일요일 표시는 첫 칸이 아니라 `dowOf(date) === 0`으로 본다.**
  주가 월요일에 시작해도 일요일이 일요일이다
- `weekStartOf`는 달을 넘어간다(8/31~9/6). `src/lib/date.test.ts`가 그 경계를 잡고 있다
- 시각 칸을 비우고 나가면 그전 값을 지킨다. **빈 시각은 알림을 조용히 죽인다**
