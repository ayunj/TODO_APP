# 색과 말투

컨셉은 **따뜻한 손그림 감성의 다이어리**. 무인양품처럼 조용하고 여백이 많게.
너무 귀엽거나 어린이 같지 않게.

---

## 색

**전부 `src/app/globals.css`의 `:root` 한 블록에서만 정한다.**
컴포넌트에 `#RRGGBB`를 직접 적지 않는다 — 토큰이 없으면 새로 만든다.

| 토큰 | 값 | 어디 |
|---|---|---|
| `--bg` | `#FAF6F0` | 배경 (크림) |
| `--card` | `#FFFFFF` | 카드 |
| `--accent` | `#D97A5E` | 앱 강조색 (코랄) |
| `--accent-soft` | `#F4D7CC` | 옅은 강조 |
| `--accent-tint` | `#FCF2ED` | 안 눌린 칩 바탕 |
| `--ok` | `#73B79F` | **완료 체크 (세이지)** |
| `--ink` / `--ink2` / `--ink3` | `#615953` / `#8C8078` / `#A59A92` | 글자 세 단계 |
| `--line` / `--line2` | `#EFE8DF` / `#F5EFE7` | 구분선 |
| `--track` | `#F2ECE6` | 진행 막대 홈 |
| `--edge` | `#D8D3CE` | 안 채운 체크 테두리 |
| `--done` `--faint` | `#D9D2CB` | 흐린 것들 |
| `--cycle` `--star` `--high` `--danger-soft` | | 주기 · 별 · 삭제 · 위험 바탕 |

### 정한 것

- **`--accent`는 고정이다.** 카테고리를 눌러도 안 바뀐다
- **완료는 코랄이 아니라 세이지**다. 강조색과 역할을 나눈다
- 그림자는 한 겹 부드럽게 — 카드 `0 8px 24px rgba(0,0,0,.05)`
- 모서리 20px, 시트 26px. 여백은 넉넉하게
- 카테고리 색은 팔레트 10개. 칩이 안 눌렸을 땐 정해둔 아주 옅은 틴트

### 틴트와 밴드 — 색 하나를 옅게 쓰는 두 가지

| | 함수 | 어디에 |
|---|---|---|
| **틴트** (아주 옅음 + 그 색 글씨) | `tintOf` | **고르는 칩** — 필터 줄, 방 칩 줄, 나누기 칩, 배지 |
| **밴드** (34% + 검은 글씨) | `bandOf` | **글자를 얹는 바탕** — 달력 칸, 방 이름표 |

**같은 것은 어느 화면에서나 같은 색이어야 한다.** 장보기·메모의 방 칩 줄만
밴드를 깔고 있어서, 같은 방이 할 일 화면에서는 옅게 회사 화면에서는 진하게 보였다.
고르는 칩이면 틴트다 — 자리가 달라도 하는 일이 같으면 같은 색을 쓴다.

### 글꼴

| 곳 | 글꼴 |
|---|---|
| 제목, 숫자 크게 | `Gowun Dodum` (둥근 손글씨 느낌) |
| 본문 | `Noto Sans KR` |
| 숫자·날짜 | `IBM Plex Mono` (자릿수가 흔들리지 않게) |

## 그림

손그림 토마토 한 마리가 앱의 상태를 표정으로 한 번 더 말한다.
원본은 컷 열 개가 든 시트 한 장이고, 스크립트가 잘라서 `public/tomato/*.png`로 넣는다.

```bash
npm run tomato [원본경로]   # 없으면 assets/tomato-sheet.png를 본다
```

좌표를 손으로 박아두지 않는다. 투명한 자리를 읽어서 컷 경계를 스스로 찾는다 —
원본을 다시 뽑을 때 크기가 조금만 달라져도 손으로 박은 좌표는 전부 어긋나기 때문이다.

**토마토 아래 붙은 라벨은 버리고, 위에 뜬 zzz·땀방울·말풍선은 남긴다.**
기준은 "가장 큰 덩어리까지" — 라벨은 늘 토마토보다 작고 늘 아래에 있다.

### 어느 컷이 어디에

| 컷 | 어디에 |
|---|---|
| `empty` 자는 것 | 일별 화면 빈 목록 |
| `busy` 땀 흘리는 것 | 진행 막대 — 아직 하나도 안 했고 다섯 개 넘게 쌓였을 때 |
| `cheer` 화이팅 | 진행 막대 — 아직 안 했지만 몇 개 안 될 때 · 즐겨찾기·기록 빈 자리 |
| `one` 눈 동그란 것 | 진행 막대 — 하다 만 중간 |
| `all` 만세 | 진행 막대 다 참 · `다 끝났습니다` |
| `cycle` 삽 든 것 | 반복이 다음 회차를 낳을 때 뜨는 토스트 |
| `heart` 하트 안은 것 | 첫 화면 |
| `peek` 빼꼼 | 장보기 빈 목록 · 휴지통 |
| `rest` 음료수 | `다 담았습니다` |
| `run` 메모 들고 뛰는 것 | 메모 빈 자리 |

### 정한 것

- **그림이 글자를 대신하지 않는다.** 옆에 늘 같은 뜻의 문장이 있고 그림은 거들기만 한다.
  그래서 읽어주는 기계에는 감춘다(`aria-hidden`, 빈 `alt`)
- **그림이 없어도 앱은 그대로 돈다.** 원본은 개인 그림이라 저장소에 없을 수 있다.
  못 불러오면 조용히 사라진다 — 깨진 그림이 뜨는 자리를 만들지 않는다.
  첫 화면만 자리가 비면 허전해서 예전 체크리스트 그림을 대체로 둔다
- **토스트에 늘 붙이지는 않는다.** 미룬 것·지운 것까지 그림이 따라다니면 그림이 값을 잃는다.
  주기가 돌아왔을 때만 붙인다

## 로고

원본은 3:1 캔버스 한가운데에 글자가 떠 있다. 그대로 쓰면 높이의 태반이 빈칸이라
헤더에서 작게 앉아 버린다. 둘레를 깎아 **글자 높이 = 그림 높이**로 맞춘다.

```bash
npm run logo [원본경로]   # 없으면 assets/logo.png를 본다
```

헤더 윗줄 왼쪽에만 쓴다. 안 뜨면 조용히 물러난다 — 아랫줄 날짜가 화면을 알려준다.

## 말투

화면에 나가는 글, 주석, 커밋 메시지 모두 한국어다.

- **명령하지 않고 거들어준다.** `추가하세요` 보다 `적어두세요`
- **숫자를 세는 대신 말로** — `세 가지 중에 한 가지 했어요`
- 빈 상태는 탓하지 않는다 — `오늘은 아직 비어 있습니다`
- 밀린 일도 `3일 지남`이라고만. 느낌표를 안 쓴다

```ts
saying(1, 3)  // '세 가지 중에 한 가지 했어요'
saying(0, 3)  // '세 가지가 기다리고 있어요'
saying(3, 3)  // '세 가지 모두 했어요'
```

## 주석

**무엇이 아니라 왜를 적는다.** 코드를 보면 아는 것은 쓰지 않고, 보면 모르는 것만 남긴다.

```ts
// 나쁨: 다음 회차를 만든다
// 좋음: 완료일만 기준으로 잡으면 미리 체크했을 때 같은 날 두 건이 생긴다
```
