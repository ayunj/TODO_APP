# 색과 말투 — 파일

| 파일 | 하는 일 |
|---|---|
| `src/app/globals.css` | ★ **색은 여기 `:root` 한 블록에서만.** 시트 애니메이션, `.field-input`, `.wrap` |
| `tailwind.config.ts` | CSS 변수를 Tailwind 색 이름으로 잇는다. 그림자·모서리·글꼴 |
| `src/lib/constants.ts` | `PALETTE`(10색), `CATEGORY_TINT`, `LEGACY_COLOR`, `saying()`, `PRIORITY_LABEL` |
| `src/app/layout.tsx` | 구글 폰트, `themeColor` |
| `scripts/make-icons.mjs` | 강조색이 바뀌면 `npm run icons`로 앱 아이콘 다시 뽑기 |
| `src/components/Tomato.tsx` | ★ 손그림 토마토 컷 하나를 그린다. 못 불러오면 사라진다 |
| `scripts/cut-tomato.mjs` | 시트 한 장을 컷 열 개로 자른다 — `npm run tomato` |
| `assets/tomato-sheet.png` | 원본 시트(컷 10개). 저장소에 없을 수 있다 |
| `assets/logo.png` | 로고 원본 (3:1 캔버스). `npm run logo`가 여백을 깎아 `public/logo.png`로 보낸다 |
| `assets/login_logo.png` | 로그인·첫 화면 그림. 같은 명령이 `public/login_logo.png`로 보낸다 |
| `src/components/Header.tsx` | 윗줄 왼쪽에 로고 |
| `src/components/WelcomeArt.tsx` | 로그인·첫 화면·새 비밀번호 위의 곰돌이 |

## 색을 바꿀 때 지날 곳

```
globals.css :root        토큰
constants.ts PALETTE     카테고리 팔레트
constants.ts LEGACY_COLOR  이미 저장된 카테고리 옮김표
tailwind.config.ts       새 토큰이면 색 이름도 잇는다
layout.tsx themeColor    브라우저 주소창 색
manifest.webmanifest     PWA 배경·테마색
scripts/make-icons.mjs   BRAND 상수 → npm run icons
```

일곱 군데다. 한 곳이라도 빠지면 어긋난다.

## 조심할 것

- **Tailwind 설정을 고쳤으면 `.next`를 지우고 다시 띄운다.**
  서버만 재시작하면 이전 CSS가 그대로 나온다.
  새 색 클래스가 통째로 빠져서 "별이 안 채워진다"로 한참 헤맸다

  ```bash
  rm -rf .next && npm run dev
  ```

- **`button`에 `text-align: inherit`를 주지 않는다.** 브라우저 기본값은 가운데인데
  이걸 주면 본문의 왼쪽 정렬을 물려받아 **모든 버튼 글자가 왼쪽에 붙는다.**
  줄처럼 쓰는 버튼은 각자 `text-left`를 단다
- **입력 칸 포커스 테두리는 `outline-offset: -2px`.**
  바깥으로 그리면 그 2px이 고정 헤더 영역으로 삐져나가 덮인다
- 새 색이 필요하면 임시로 `bg-[#XXXXXX]`를 쓰지 말고 토큰을 만든다.
  흩어진 하드코딩 아홉 군데를 나중에 걷어내느라 한 번 고생했다
