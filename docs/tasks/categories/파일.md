# 카테고리 — 파일

| 파일 | 하는 일 |
|---|---|
| `src/lib/constants.ts` | `PALETTE`(10색), `CATEGORY_TINT`(칩 바탕), `DEFAULT_CATEGORIES`(둘), `LEGACY_COLOR`(지난 팔레트 옮김표) |
| `src/components/CategoryFilter.tsx` | 필터 칩 줄 (내 것 \| 방마다 가는 줄) + 사람 줄 |
| `src/screens/settings/CategoryListScreen.tsx` | 목록 · 사용 개수 · 나눈 방 표시 |
| `src/screens/settings/CategoryScreen.tsx` | 한 겹 안 — 이름 · 색 · 지운 것 · 지우기 (새 카테고리도 여기) |
| `src/components/form.tsx` | `CategoryPicker`(폼에서 고르기), `ColorPicker`(팔레트) |
| `src/lib/store.tsx` | `addCategory` `updateCategory` `removeCategory`(옮긴 개수를 돌려준다) |
| `src/lib/selectors.ts` | `matches(item, filter)` |

## 조심할 것

- **id를 고정 문자열로 쓰지 않는다.** 예전엔 `'home'` 같은 걸 기본값으로 썼는데,
  서버 컬럼이 `uuid`라 그대로 올리면 거부당한다.
  기본 카테고리도 만들 때 새 uuid를 매긴다
- 기기마다 기본 카테고리를 따로 만들면 `집안일`이 두 벌이 된다.
  그래서 **서버와 맞춘 뒤에** 심고, 이미 양쪽에 생겼으면 이름이 같은 것끼리 합친다
  (`repo/synced.ts`의 `alignCategories`, [../../account/sync/기능.md](../../account/sync/기능.md))
- 색을 바꾸면 `LEGACY_COLOR`에 옮김표를 더한다. 이미 저장된 카테고리도 같이 옮겨진다
- 카테고리는 **시트가 아니라 화면**이다. 목록도 한 겹 안도 `Route`로 들어간다 —
  시트 위에 시트를 쌓으면 어디까지 왔는지가 안 보인다
- 지울 때 옮겨지는 개수는 **살아 있는 것만** 센다.
  지운 것도 같이 옮기긴 한다 — 안 그러면 되돌렸을 때 없는 카테고리를 가리킨다
