# 반복 주기 — 파일

| 파일 | 하는 일 |
|---|---|
| `src/lib/repeat.ts` | ★ `baseOf` `spawnNext` `isRepeatFinished` `cycleProgress` |
| `src/lib/repeat.test.ts` | 필수 3케이스. `npm test` |
| `src/lib/store.tsx` | `toggleTask` — `doneOn`을 그 날로 찍고 다음 회차, 취소하면 거둔다 |
| `src/lib/store.tsx` | `removeTask` — 그 한 건만. 자식은 `parentId`만 끊는다 |
| `src/lib/store.tsx` | `updateTask` — 주기·종료일이 바뀌면 대기 회차를 다시 맞춘다 |

| `src/sheets/TaskFormFields.tsx` | 주기·종료일 입력과 안내 문구 |

## 함수 넷

```ts
baseOf(task)                   // 다음 회차의 기준일 = task.date
spawnNext(task)                // 다음 1건. 종료일을 넘기면 null
isRepeatFinished(task)         // 종료일이 지나 더 안 만드는 경우인지
cycleProgress(task, today)     // { total, gone, pct } — 여기만 오늘이 필요하다
```

## 조심할 것

- `repeat.ts`를 고치면 **`repeat.test.ts`를 먼저 읽는다.**
  세 케이스가 다 실제로 터졌던 버그를 막고 있다
- 삭제·완료취소 동작은 스토어 안에 있어서 **테스트가 안 잡아준다.**
  손으로 눌러봐야 안다. 이 두 개는 실제로 한 번 어긋난 적이 있다
