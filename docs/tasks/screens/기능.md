# 세 화면

탭바의 `일 / 월 / 기록`. 같은 데이터를 세 각도로 본다.

## 일별

```
진행 스트립      세 가지 중에 한 가지 했어요        1 / 3
즐겨찾기 칩      [화장실 청소 8d] [빨래 4d] …
목록             미완료 (우선순위 높은 순) → 완료 (아래, 취소선)
미루기           남은 3개 내일로 미루기   [📅]
추가             + 새 할 일 추가하기
지난 미완료      접힌 채로. 오늘 화면에서만
```

**완료한 것을 숨기지 않는다.** 아래로 내리고 취소선만 긋는다. 오늘 뭘 했는지 보이는 게 낫다.

**지난 미완료를 빨갛게 칠하지 않는다.** `3일 지남`이라고만 적는다. 밀린 일이 있었을 때
앱이 다그치기 시작하면 안 열게 된다.

### 할 일 한 줄

```
☐  화장실 청소 ★
   ┌ 세면대 밑까지 ┐        ← 메모. 일별 화면에서만 보인다
   ● 집안일 · 8일마다 · ~08.31까지 · 3일 지남
   ▬▬▬▬▬░░░░               ← 반복이면 주기 진행률
                      → ×   ← 미루기 / 삭제
```

**메모는 일별에서만 보인다.** 월별·기록에 메모까지 나오면 화면이 빽빽해진다.

## 월별

달력 칸마다 **그날 할 일 제목 최대 3개**, 넘치면 `+N`. 완료한 건 취소선.

**카테고리는 제목 옆의 점이 아니라 글씨 바탕으로 말한다.**
칸 하나가 폰에서 46px인데 점 4px + 간격 3px이 글자 자리를 7px 먹었다.
바탕으로 옮기니 작은 점보다 눈에 잘 띄고, 되찾은 7px은 전부 글자 수로 갔다.

**글씨 크기도 폭도 그대로 두는 게 맞았다.** 한 번 키워봤다가 되돌렸다.

| 해본 것 | 결과 |
|---|---|
| 글씨 9 → 10px | 글자 수가 줄어 `빨래 널기`가 `빨래 …`가 됐다 |
| 화면 여백 밖으로 8px + 카드·간격 줄이기 | 칸 46.3 → 50.6px. **반 자**(4.7 → 5.2) |
| 여백을 아예 0으로 | 6.3자. 한 자 얻자고 여백을 다 버리는 셈 |

7칸을 390px에 나누는 한 못 벗어나는 한계다. 네 자 남짓 보이고 나머지는 눌러서 들어간다.
어차피 "무슨 날에 뭘 하는지"를 아는 자리지 목록을 읽는 자리가 아니다.

**막대 그래프로 바꾸지 않는다.** 통계가 아니라 "무슨 날에 뭘 하는지"가 보여야 한다.
위에 `할 일 / 완료 / 달성률` 세 숫자 한 줄이면 통계는 충분하다.

칸을 누르면 그날 일별 화면으로 간다.

## 기록

되풀이하는 일을 **격자**로 칠한다. 습관 트래커 모양. 격자 이름은 `반복 기록`.

- **행** = 그 폭에 등장한 제목 하나 (즐겨찾기에 있거나 주기가 설정된 제목)
- **열** = 그 폭의 하루하루
- 칸 색: 했음(카테고리 색) / 예정(같은 색 흐리게) / 없음(회색)

**"이번 달에 청소를 몇 번 했나"를 세는 게 아니라 흐름이 보이게 하는 것이다.**
빈칸이 이어지는 게 보이면 그걸로 충분하다.

제목을 칸 **위에** 올려서 격자가 카드 폭을 다 쓰게 했다. 옆에 두면 31칸이 좁은 칸에 밀려
한 칸이 9px밖에 안 된다.

### 폭이 둘 — 주간과 월간

맨 위 세그먼트로 고른다. **한 달치는 칸이 작아 하루하루가 안 보이고, 주간은 칸이 커서
요일이 들어간다.**

| | 월간 | 주간 |
|---|---|---|
| 열 | 1일 ~ 말일 | 일곱 칸 |
| 요일 머리 | 없음 (칸이 좁아 글자가 안 들어간다) | 있음 |
| 카테고리 막대 | 있음 | **없음** |
| 제목 | `8월 기록` | `8월 10일 주` |
| `‹ ›` | 한 달씩 | **한 주씩** |

**주간에 카테고리 막대를 안 그린다.** 한 주치는 표본이 적어 `2/3` 같은 숫자가
아무 말도 안 한다.

주가 **월요일에 시작할지 일요일에 시작할지는 [앱 설정](../../app/prefs/기능.md)에서 고른다.**

### 격자에서 눈금을 뺐다

`1 5 10 15 …` 눈금이 있었는데 없앴다. **숫자를 세려고 보는 화면이 아니라 흐름을 보는
화면**이다. 오늘 칸만 테두리로 짚어주고, 날짜를 정확히 짚어야 하면 그날로 들어가면 된다.

### 주간 칸은 34px로 묶는다

일곱 칸을 화면 폭에 나눠 담으면 한 칸이 60px 가까이 된다. **격자는 크게 그린다고 더
읽히는 그림이 아니다.** 칸을 묶고 남는 폭은 그냥 비워둔다.
