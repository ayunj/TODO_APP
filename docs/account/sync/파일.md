# 동기화 — 파일

| 파일 | 하는 일 |
|---|---|
| `src/lib/repo/synced.ts` | ★ 로컬을 감싸 서버와 맞춘다. 여기가 전부다 |
| `src/lib/repo/remote.ts` | 서버 한 겹. 카멜케이스 ↔ 스네이크케이스, `pull` `push` `drop` |
| `src/lib/repo/index.ts` | `getRepository(owner)` — 로그인 전엔 로컬, 후엔 감싼 것 |
| `src/lib/repository.ts` | 인터페이스. `sync?()`와 무덤 셋(`remember` `graves` `forget`) |
| `src/lib/repo/indexeddb.ts` | `graveyard` 스토어, `Settings.syncedAt` `ownerId` |
| `src/lib/store.tsx` | 로컬을 먼저 그리고 → 맞추고 → 다시 그린다 |
| `src/lib/id.ts` | `uid()`(uuid), `isUuid()` |

## synced.ts 안의 조각들

| 함수 | 하는 일 |
|---|---|
| `sync()` | 전체 흐름. 주인 확인 → id 옮김 → 무덤 비우기 → pull → 합치기 |
| `settle(kind, mine, theirs, since)` | ★ 한 종류를 합친다. 규칙 네 줄이 여기 |
| `handOver(previous)` | 주인이 바뀌었으면 로컬을 비운다 |
| `alignCategories(theirs)` | 이름이 같은 카테고리를 서버 것으로 몰아준다 |
| `uuidify()` | 옛 id에 새 uuid를 매기고 참조도 옮긴다 |
| `flushGraves()` | 지웠다고 적어둔 것을 서버에 알린다 |
| `save` / `erase` | 로컬 먼저, 서버는 뒤따라 (실패해도 안 막는다) |

## 흐름

```
store 로드
  ├ 로컬 스냅샷으로 화면을 먼저 그린다 (서버를 안 기다린다)
  ├ repo.sync()
  │    handOver → uuidify → flushGraves → pull → settle × 5 → syncedAt 갱신
  └ 합쳐진 걸로 다시 그린다 → furnish (빈 곳 채우기)
```

## 조심할 것

- **`this.local`과 `this`를 헷갈리지 않는다.**
  `this.local.deleteCategory`는 로컬만, `this.deleteCategory`는 서버에도 알린다.
  `alignCategories`에서 서버 것을 지워버리면 안 된다
- `furnish`(기본값 심기)는 **맞춘 뒤에** 부른다. 먼저 심으면 두 벌이 된다
- 새 데이터 종류를 더할 때 지나야 하는 곳:
  `types.ts` → `repository.ts` → `repo/indexeddb.ts` → `repo/memory.ts` →
  `repo/remote.ts` → `repo/synced.ts` → `store.tsx`
