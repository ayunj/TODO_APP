# 로그인 — 파일

| 파일 | 하는 일 |
|---|---|
| `src/lib/supabase.ts` | 클라이언트. **쓸 때 가서 받아온다** (`import()`) |
| `src/lib/auth.tsx` | 세션, 이메일 로그인·가입, 익명 로그인, 재설정. 영어 오류를 한글로 |
| `src/screens/LoginScreen.tsx` | 로그인 · 가입 · 비밀번호 찾기. 초대 링크면 이름 한 칸 |
| `src/screens/NewPasswordScreen.tsx` | 재설정 메일로 돌아왔을 때 |
| `src/sheets/AccountSheet.tsx` | 로그인한 사람, 로그아웃. **방·초대 링크가 붙을 자리** |
| `src/sheets/SettingsSheet.tsx` | 톱니 안 `계정` 항목 |
| `src/components/AppShell.tsx` | 로딩 → 첫 화면 → 로그인 → 새 비밀번호 → 본 화면 |
| `src/app/providers.tsx` | `AuthProvider`가 제일 바깥 |
| `.env.example` | 열쇠 견본. 실제 값은 `.env.local`(git에 안 올라감) |

## 왜 늦게 불러오나

`supabase.ts`가 위에서 그냥 `import`하면 **60KB짜리 짐이 열쇠 없는 사람 화면에도 실린다.**
실제로 첫 화면 크기가 127KB → 194KB로 뛰었다가, 늦게 불러오게 바꿔 132KB로 돌아왔다.

## 오류 문구

Supabase의 영어 메시지를 한글로 옮긴다. **못 알아본 것은 원문을 그대로 내보낸다** —
뭉뚱그린 문구보다 낫다.

`For security purposes, you can only request this after 57 seconds` 같은 건
숫자를 살려서 `조금 빨랐어요. 57초 뒤에 다시 눌러주세요`로 바꾼다.

## 조심할 것

- `detectSessionInUrl: true`. 재설정 링크가 주소의 `#` 뒤에 실려 온다.
  초대 링크의 `?join=`은 `?` 뒤라 서로 안 건드린다
- 새 비밀번호를 정한 뒤 `history.replaceState`로 토큰을 지운다
- **열쇠 없이 로그인 벽을 세우지 않는다.** `hasSupabase`가 그 판단을 한다
