# 로그인

**로그인해야 들어온다.** 첫날부터 백업되고, 나중에 합칠 일이 안 생긴다.

---

## 두 갈래

### 본인 — 이메일 + 비밀번호

```
        오늘도 하나씩
  로그인하면 백업되고, 다른 기기에서도
        같이 쓸 수도 있어요.

  [ 이메일       ]
  [ 비밀번호     ]
  [   로그인     ]

  계정이 없으신가요? 새로 만들기
  비밀번호를 잊으셨나요?
```

매직 링크(메일로 로그인) 대신 비밀번호를 쓴다. Supabase 무료 플랜은 메일을 시간당 몇 통밖에
못 보내서 매직 링크가 오히려 답답하고, 폰에 설치한 PWA에서 메일 링크를 누르면
브라우저로 열려서 흐름이 끊긴다. 한 번 로그인하면 세션이 유지돼 자주 할 일도 없다.

### 초대받은 사람 — 이름 한 칸

`?join=코드`로 들어오면 **이름 한 칸**만 보인다. 뒤에서 익명 로그인이 돌지만 본인에겐 안 보인다.
이메일도 비밀번호도 없다.

**가입을 시키려다 앱이 죽는 지점이 대부분 여기다.** 한쪽만 앱을 깔고 있으면 오래 못 간다.

나중에 그 사람이 자기 기기 여러 대에서 쓰고 싶어지면, **그 익명 계정에 이메일만 붙이면 된다.**
쌓인 것도 그대로 남는다.

## 비밀번호 찾기

이메일을 넣으면 재설정 링크가 간다. 링크로 돌아오면 **새 비밀번호를 정하기 전까지 그 화면에 머문다** —
링크를 누른 시점에 이미 세션이 생기기 때문에, 그냥 두면 비밀번호를 안 정한 채 들어가버린다.

정하고 나면 주소에 남은 토큰을 지운다. 안 지우면 새로고침할 때마다 또 뜬다.

## 로그아웃

설정(톱니) → **계정**. 로그인한 이메일이 보이고 로그아웃 버튼이 있다.
나가면 로그인 화면으로 돌아간다. **로그아웃이 로컬 데이터를 지우지는 않는다.**

## 열쇠가 없으면 로그인을 걸지 않는다

`NEXT_PUBLIC_SUPABASE_*`가 비어 있으면 로그인 화면 자체가 안 뜨고 1단계처럼 그냥 쓴다.

접속할 곳을 모르는 채로 벽만 세우면 **로그인은 전부 실패하는데 할 일 목록에는 영영 못 들어간다.**
폰에 설치해둔 앱이 그렇게 잠기면 곤란하다.

---

## Supabase 쪽 설정

| 어디 | 무엇 |
|---|---|
| Authentication → Sign In / Providers → Email | `Confirm email` **끄기** (무료 메일 한도에 막힌다) |
| 같은 곳 | `Anonymous sign-ins` **켜기** (초대 링크용) |
| Authentication → URL Configuration | `Site URL`을 배포 주소로. 기본값 `localhost:3000`이면 재설정 링크가 폰에서 안 열린다 |

## 공개할 거면 더 필요한 것

- **비밀번호 찾기** — 있다 ✓
- **이메일 확인** — 지금 꺼놨다. 켜면 커스텀 SMTP가 필요하다
- Supabase 무료는 **일주일 아무도 안 쓰면 프로젝트가 잠깐 멈춘다**
