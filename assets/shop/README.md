# 상점 그림

**그린 원본을 여기 놓는다.** [상점 채우기](../../design/관리자.html)에서 올리면
Supabase Storage의 `shop` 통에 **여기와 똑같은 자리**로 들어간다.

```
<대분류>/<중분류>/<종류>/<코드>.png

deco/daily/gomdori/0000001.png          꾸미기 > 일상 > 곰
deco/room/background/0000020.png        꾸미기 > 룸 > 배경
season/holiday/prop/0000016.png         시즌 > 기념일 > 소품
```

| 자리 | 어디서 오나 |
|---|---|
| 대분류 | `shop_group.group_key` — `deco` · `season` |
| 중분류 | `shop_family.family_key` — 관리자가 늘린다. **열쇠가 곧 폴더 이름이다** |
| 종류 | `gomdori`(캐릭터) · `background`(배경) · `prop`(소품 든 캐릭터) |
| 코드 | `costume_catalog.item_key` — `0000001`부터 자동으로 딴다 |

**폴더는 미리 다 안 만들어 둔다.** 중분류는 관리자가 늘리는 것이라,
새 중분류를 만들면 그 폴더도 그때 생긴다. 여기 있는 것은 지금 심어둔 다섯뿐이다.

## 규격

| 종류 | 그림 |
|---|---|
| `gomdori` 캐릭터 | PNG · **배경 투명** · 세로로 긴 한 장. 앞모습만 쓴다 |
| `background` 배경 | PNG · **정사각** · 배경까지 꽉 차게. 위아래가 잘리니 가운데를 비워둔다 |
| `prop` 소품 든 캐릭터 | PNG · 배경 투명 · **소품까지 든 한 장.** 옷 위에 얹는 조각이 아니다 |

## 앱과 같이 나가는 그림은 여기가 아니다

`public/gomdori/`에 있는 것은 **앱에 박혀 나가는 그림**이다 —
상점이 오프라인에서도 떠야 해서 기본 곰돌이와 기본 룸은 앱이 들고 있다.
그 원본은 [`assets/gomdori/`](../gomdori)에 있고 `npm run gomdori`로 다듬는다.

여기 있는 것은 **나중에 올리는 것**이라 앱을 새로 안 내도 상점에 뜬다.
